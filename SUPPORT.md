# Support

Start with the [README](README.md), [source inventory](LISTS.md) and [accessibility guidance](ACCESSIBILITY.md).

- **Setup and list selection:** start with Balanced and add optional profiles only when their restrictions are wanted.
- **A site stopped working:** temporarily disable the affected subscription, update Pi-hole gravity, and confirm which domain is responsible before requesting an exception. Avoid broad allowlists.
- **Bug or false positive:** open a [repository issue](https://github.com/mickpletcher/PiHole-Blocklist/issues/new/choose), including the relevant profile, public domain, expected behavior and reproduction steps.
- **Pi-hole itself:** consult the [Pi-hole documentation](https://docs.pi-hole.net/) and [Pi-hole community](https://discourse.pi-hole.net/).
- **Security:** use the private route in [SECURITY.md](SECURITY.md).

Support is community-maintained and best effort, with no guaranteed response time. Remove client IP addresses, tokens, private domains and browsing history from reports. Do not upload a complete Pi-hole query log.
